# Global Offers 2026 (free, optional; live from Sat 14 Nov)

Source: https://www.spaceappschallenge.org/2026/global-offers/ (announced by the organisers in the kickoff email).
Terms and claim steps are on that page; none of these are required. Cite any one we use in `submission/data-citations.md`.

| Collaborator | What they offer | Use for Field Shift |
|---|---|---|
| GoDaddy | Free domain + 1 year of website hosting for participants | Public URL for the demo (T-017). Cheap win for the project link |
| Google Cloud | GCP, Firebase, Google Maps API, and its AI/ML services | Hosting/Firebase for the demo; Maps tiles if MapLibre is not enough; optional LLM for the "explainer" |
| Meteomatics | Weather, marine, environmental and climate data API | Possible cross-check for rain/temperature against POWER/IMERG (shows uncertainty); a non-NASA source, so cite and check license |
| Microsoft | Azure, Planetary Computer, Copilot, GitHub Copilot, Teams | Planetary Computer offers Sentinel-2, Landsat, MODIS, NASADEM/SRTM via STAC: a faster route than AppEEARS for T-013 |
| Miro | Education/Business plan, Space Apps board templates | Whiteboard (the team already used the paper canvas); optional for the pitch flow |

## Notes
- All optional. Do not make the demo depend on any of them (offline cache stays the rule, AGENTS.md §6).
- Worth checking first: Microsoft Planetary Computer (T-013) and GoDaddy domain (T-017).
- Creating accounts or claiming offers is a human step (each person for their own account).
